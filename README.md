# Kill Steve, A Game by Keith Perez for a Top-Down SNES Era Jam

[Play Here](https://keithperez.itch.io/kill-steve)

This game was created as a submission to the [Top-Down SNES Era Jam](https://itch.io/jam/the-top-down-snes-era-jam) where applicants had around a month to submit a game made from scratch. I took this whole time to learn how to use Godot and GDScript to make this game. With help from others listed in the itch.io page, this is the game I submitted for the jam.
